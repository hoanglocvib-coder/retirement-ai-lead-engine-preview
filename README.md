# LPBank retirement information landing page — preview

This repository contains only the static, no-data-collection preview artifact
for review. It is deployed through GitHub Pages. The private source repository
retains the evidence, operating boundaries and release-gate records.

The page has no form, analytics, chatbot, CRM, recording or customer-data
storage. It links visitors to LPBank official product information and presents
a private consultation call route that is explicitly not an LPBank hotline.
